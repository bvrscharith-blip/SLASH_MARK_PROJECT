# TASK 5 - AI Self Driving Cars

## Project Overview
This project implements basic lane detection for self-driving cars using OpenCV and Computer Vision techniques.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Features
- Road image processing
- Grayscale conversion
- Edge detection using Canny algorithm
- Lane detection visualization
- Basic perception pipeline
- Jupyter Notebook implementation

## Project Workflow
1. Import Libraries
2. Load Road Image
3. Convert Image to Grayscale
4. Apply Canny Edge Detection
5. Detect Lane Edges
6. Display Lane Detection Output

## Output
Implemented lane detection and basic perception pipeline for autonomous driving using OpenCV.
## Conclusion
Successfully developed a basic AI Self-Driving Car lane detection system using OpenCV and Computer Vision.
