# Sentiment Analysis Project

This project predicts the sentiment of reviews using AI.

Sentiments:
- Positive
- Negative
- Neutral

Technologies Used:
- Python
- Pandas
- Scikit-Learn
- TF-IDF
- Logistic Regression
- Jupyter Notebook

Example:

Input: Food was awesome 
Output: Positive Review

Input: Food was bad
Output: Negative Review

Input: Food was okay  
Output: Neutral Review
