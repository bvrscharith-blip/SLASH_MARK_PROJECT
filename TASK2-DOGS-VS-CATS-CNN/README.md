# TASK 2 - Dogs vs Cats CNN Classifier

## Project Overview
This project uses Convolutional Neural Networks (CNN) with TensorFlow/Keras to classify images of Dogs and Cats.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Features
- Image preprocessing
- CNN model training
- Dog and Cat image classification
- Prediction using trained CNN model
- Jupyter Notebook implementation

## Project Workflow
1. Import Libraries
2. Load Dataset
3. Build CNN Model
4. Compile Model
5. Train Model
6. Predict Dog/Cat Images

## Output
The model successfully predicts whether the given image is a Dog or Cat.
