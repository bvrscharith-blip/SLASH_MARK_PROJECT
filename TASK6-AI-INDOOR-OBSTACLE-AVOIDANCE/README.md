# TASK 6 - AI Powered Indoor Obstacle Avoidance

## Project Overview
This project implements an AI-powered indoor obstacle avoidance system using Computer Vision and OpenCV techniques. The system is designed to simulate indoor navigation for autonomous robots and drones by detecting obstacles and environment boundaries.

## Objective
The main objective of this project is to build a basic AI perception and obstacle detection pipeline that can identify indoor obstacles and assist in safe autonomous navigation.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Libraries Used
- cv2
- numpy
- matplotlib.pyplot

## Features
- Indoor environment image processing
- Obstacle detection using edge detection
- Grayscale image conversion
- Canny edge detection algorithm
- Obstacle boundary visualization
- Basic AI perception pipeline
- Indoor navigation simulation
- Jupyter Notebook implementation

## Project Workflow
1. Import Required Libraries
2. Load Indoor Environment Image
3. Convert Image to RGB Format
4. Convert Image to Grayscale
5. Apply Canny Edge Detection
6. Detect Obstacles and Boundaries
7. Visualize Original Environment and Detected Obstacles

## Learning Outcomes
- Computer Vision fundamentals
- Obstacle detection techniques
- Indoor navigation basics
- AI perception systems
- OpenCV image processing
- Autonomous navigation concepts

## Real-World Applications
- Autonomous indoor robots
- Smart warehouse navigation
- Drone obstacle avoidance
- Service robots

## Output
The system successfully detects indoor obstacles and environment boundaries from indoor navigation images using OpenCV-based edge detection techniques.
