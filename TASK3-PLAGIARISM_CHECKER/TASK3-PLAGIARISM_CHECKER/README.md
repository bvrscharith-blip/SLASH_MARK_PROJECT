# AI Based Plagiarism Checker

## Description
This project detects plagiarism between documents using NLP techniques. It compares text documents and calculates similarity using TF-IDF and Cosine Similarity.

## Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas

## Libraries Used
```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
```

## Features
- Compare multiple documents
- Detect similar text
- Calculate similarity percentage
- Identify potential plagiarism

## How to Run
1. Open `SMS03 (1).ipynb`
2. Run all cells in Jupyter Notebook
3. View plagiarism detection results
