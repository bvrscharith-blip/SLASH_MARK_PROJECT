# TASK 4 - Credit Card Fraud Detection

This project uses AI to detect fraudulent credit card transactions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Features
- Data preprocessing
- Fraud detection
- Logistic Regression model
- Accuracy evaluation
- Genuine/Fraud prediction

## Output
The model predicts whether a transaction is Genuine or Fraudulent.
